# 写真 → PDF 変換ツール

複数の写真をブラウザ上だけでPDFにまとめる、シンプルな静的ツールです。
サーバーへのアップロードは一切行わず、すべての処理は端末（ブラウザ）内で完結します。

## 使い方

1. `index.html` をブラウザで開きます（ダブルクリックでOK、または任意の静的ホスティングに配置）。
2. 「クリックして写真を選択」またはドラッグ＆ドロップで、変換したい写真（複数可）を追加します。
3. 必要に応じてサムネイルをドラッグして順番を入れ替えたり、×ボタンで不要な写真を削除します。
4. ページサイズ（A4 / Letter / 写真のサイズに合わせる）とJPEG画質を選択します。
5. 「PDFに変換してダウンロード」をクリックすると、1つのPDFファイルとしてダウンロードされます。

## 特徴

- 完全にクライアントサイドで動作（外部ライブラリ・サーバー通信なし）
- JPEG / PNG / WebP / GIF などブラウザが読み込める画像形式に対応
- 写真ごとに縦横比を保ったまま自動でページ向き（縦/横）を選択
- A4・Letter・原寸（写真サイズ）の3種類のページレイアウトに対応
- JPEG画質を調整してファイルサイズを最適化可能

## 技術的な仕組み

`index.html` 単体で完結しており、ビルド手順は不要です。各写真をCanvasでJPEGに再エンコードし、
PDFのバイト列（オブジェクト・xrefテーブル・トレーラー）をJavaScriptで直接組み立てて
`DCTDecode` フィルタで画像を埋め込むことで、外部PDFライブラリなしでPDFを生成しています。
